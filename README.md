# Alizabeth-ForgeVision-Chat

ForgeVision（推想视限）手机版 —— 专用于聊天对话的 AI，默认模型 `deepseek-chat`。

纯静态网页：对话存在手机浏览器里，API 直连 DeepSeek 官方，支持切换 `deepseek-chat` / `deepseek-reasoner`。

## 用法

1. 手机浏览器打开 `https://i-alizabeth.github.io/Alizabeth-ForgeVision-Chat/`
2. **先添加到主屏幕再用**（iPhone：Safari 分享 → 添加到主屏幕；安卓：Chrome 菜单 → 安装应用）
3. 从主屏幕图标进入，设置里填自己的 DeepSeek API Key（只存在手机上）

数据在浏览器 IndexedDB 里，建议定期在「设置 → 数据 → 导出全部」存一份备份。

## 更新

桌面版源码在本地 `D:\ForgeVision`，更新 `public/` 里的文件后重新推到这个仓库即可。
